Как обрабатываются ваши данные

Прозрачно о том, что происходит с каждым значением которое вы вводите в форму.

Как работает форма

Вы вводите данные в формуБраузер отправляет значения по HTTPS напрямую на ZeroCreds сервер.
ZeroCreds записывает в защищённое хранилищеПароли и токены уходят в Google Secret Manager или Vault. ZeroCreds использует права только на запись — прочитать обратно он не может.
Агент получает только подтверждениеИИ-ассистент видит только { status: "done", secret_id: "..." } — идентификатор, но не сами данные.
Агент читает из хранилища своими ключамиЕсли агенту нужны данные — он обращается в GCP/Vault напрямую, минуя ZeroCreds. Ваши данные так и не проходят через LLM-контекст.

Гарантии

🔗
Ссылка одноразовая

Форма доступна один раз и истекает через указанное время (по умолчанию 30 минут). После заполнения ссылка перестаёт работать.

🔒
Write-only доступ к хранилищу

ZeroCreds записывает данные в Google Secret Manager с ролью secretVersionAdder. Прочитать или удалить их ZeroCreds не может — это гарантирует IAM.

🧠
Данные не попадают в LLM

ИИ-ассистент не получает ваши пароли, токены и персональные данные. Агент видит только факт успешного сохранения.

📖
Open source — можно проверить

Весь код сервера опубликован на GitHub. Эндпоинт /version возвращает текущий git-коммит для сверки.

Где теоретически может произойти утечка

Мы считаем важным говорить об этом честно.

Сценарий Вероятность Снижение риска
Компрометация ZeroCreds сервера НИЗКАЯ Self-hosted вариант, open source, минимальные зависимости
Компрометация GCP/Vault хранилища НИЗКАЯ IAM-разделение ролей, write-only для ZeroCreds
MITM при передаче КРАЙНЕ НИЗКАЯ HTTPS/TLS, сертификаты Let's Encrypt
Вредоносное расширение браузера СРЕДНЯЯ Вне контроля ZeroCreds — используйте чистый браузер
Malware на устройстве пользователя СРЕДНЯЯ Вне контроля любого веб-сервиса

Условия для сервисов, использующих ZeroCreds

Если вы подключили сервис через ZeroCreds — он обязан:

  • Хранить ваши данные только в целях, указанных при подключении.
  • Удалить персональные данные (PII) и пароли по вашему запросу в течение 30 дней. Для запроса обратитесь напрямую к сервису, который попросил вас заполнить форму.
  • Не передавать ваши данные третьим лицам без явного согласия.
  • Уведомить вас в течение 72 часов в случае инцидента безопасности, затронувшего ваши данные.

ZeroCreds предоставляет техническую инфраструктуру. Ответственность за соблюдение этих условий лежит на сервисе, выдавшем вам ссылку на форму. Подробнее о самостоятельном развёртывании: github.com/Zerocreds-com/zerocreds-server.
